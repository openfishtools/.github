## 🌟 Overview

**OpenFishTools** is a unified creative suite built to streamline motion design and editing workflows across desktop applications and modern web platforms.

### 📦 Ecosystem & Repositories

| Repository | Description | Link |
| :--- | :--- | :--- |
| **[CEP](https://github.com/openfishtools/CEP)** | Adobe After Effects CEP extension panel featuring interactive Graph Editor bezier easing, AE to Alight Motion converter, smart auto-save, and transform utilities. | [openfishtools/CEP](https://github.com/openfishtools/CEP) |
| **[Studio](https://github.com/openfishtools/Studio)** | Browser-based non-linear video editor (NLE) with WebCodecs hardware-accelerated rendering, multi-track timeline keyframing, and modular FX plugin registry. | [openfishtools/Studio](https://github.com/openfishtools/Studio) |
| **[web](https://github.com/openfishtools/web)** | Web platform, assets catalog, and cloud services for the OpenFishTools ecosystem. | [openfishtools/web](https://github.com/openfishtools/web) |
| **[web-tools](https://github.com/openfishtools/web-tools)** | Lightweight web-based utilities and helper converters for animation workflows. | [openfishtools/web-tools](https://github.com/openfishtools/web-tools) |
