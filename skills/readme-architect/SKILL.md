# OpenFishTools README Architect

This skill provides the official design framework, structural checklist, and styling standards for authoring documentation across all OpenFishTools projects (`CEP`, `Studio`, `web`, `web-tools`, and organization profiles).

## 🎨 Visual Identity Standards
- **Primary Accent**: `#9DFF00` (Electric Lime)
- **Secondary Accent**: `#229200` (Forest Green)
- **Background Anchor**: `#121212` / `#0D1117` (Dark Slate)
- **Brand Assets**: Reference SVG vectors from `assets/logo.svg` or `assets/brand-banner.svg`.

## 📐 Structural Checklist
Every production README must contain the following sections in order:
1. **Hero Header**: Centered brand icon/banner, project title, dynamic typewriter tagline, and unified `for-the-badge` status badges.
2. **Privacy / Architecture Callout**: GitHub Alert (`> [!IMPORTANT]`) emphasizing 100% client-side WebCodecs rendering and zero telemetry.
3. **Philosophy / Value Proposition**: 3 clear bullet points solving real motion design/editing pain points.
4. **Key Capabilities Grid**: A 2-column responsive HTML table highlighting 4 core strengths.
5. **Ecosystem & Sub-Projects Table**: Interactive inventory linking to active repositories with tech stack tags.
6. **Mermaid Flowchart**: Visualizing the pipeline between After Effects, Web Studio, and output targets.
7. **Quickstart Matrix**: Collapsible `<details><summary>` sections for installation and local dev instructions.
8. **Contributing & License**: Standard open-source contribution workflow under the license stated in each repository (FishTools and FishTools Studio: GNU AGPLv3).
